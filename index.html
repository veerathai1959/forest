📖 วิธีการใช้งาน
🗺 1. การตั้งค่าพื้นที่
  1. เลือก ภาค → จังหวัด → ประเภทพื้นที่
  2. พิมพ์หรือเลือก ชื่อพื้นที่ จากรายการที่แนะนำ
  3. พื้นที่ (ไร่) จะถูกเติมให้อัตโนมัติ — ถ้าไม่มีในระบบ กด ➕ เพิ่มพื้นที่ใหม่
  4. ตรวจสอบพิกัดศูนย์กลาง แล้วกด 💾 บันทึกการตั้งค่า
🔍 2. เปรียบเทียบภาพดาวเทียม
  1. แตะที่ จุดเฝ้าระวัง ในรายการด้านล่างแผนที่
  2. เลือกเลเยอร์: HLS 30 ม. / VIIRS 375 ม. / 🛰 Radar (ทะลุเมฆ)
  3. ลากเส้นกลางจอ (หรือกด ← →) เพื่อเทียบก่อน/หลัง
  4. เลือกช่วงเวลา: 5 / 15 / 30 / 90 วัน
  5. ใช้ปุ่ม ‹ › เลื่อนดูรอบก่อนหน้า/ถัดไป
🛰 3. Sentinel-1 Radar (ทะลุเมฆ)
  1. กดปุ่ม 🛰 Radar ในหน้าแจ้งเตือน → เห็นภาพเรดาร์ ไม่มีเมฆบัง ทันที
  2. หรือกด "🌍 Copernicus →" → Compare Slider จะเปลี่ยนเป็น Radar อัตโนมัติ + เปิด Copernicus Browser พร้อมกัน
  3. หรือกดปุ่ม 🛰 ที่ header เพื่อดูข้อมูล Sentinel-1 ของพื้นที่
  4. ภาพเรดาร์: สีเข้ม = น้ำ/ดิน, สีอ่อน = พืช/ป่า, สีสว่าง = สิ่งปลูกสร้าง
🔥 4. จุดความร้อน (Hotspot)
  1. กดปุ่ม 🔥 ที่มุมขวาบน
  2. สมัคร MAP_KEY ฟรีที่ NASA FIRMS
  3. วาง key → กด 💾 บันทึก → เลือกช่วงวัน → กด 🔥 โหลด
  4. สี: 🔴 สูง · 🟠 ปานกลาง · 🟢 ต่ำ (ระดับความมั่นใจ)
💾 5. บันทึก & ส่งออกข้อมูล
  1. 📥 โหลด GeoJSON — บันทึกจุดเป็นไฟล์ GIS
  2. 🧭 นำทาง — เปิด Google/Apple Maps ตามพิกัด
  3. ✅ บันทึกผล — ทำเครื่องหมายว่าตรวจแล้ว
📲 6. ติดตั้งเป็น PWA
  1. กดปุ่ม 📲 ติดตั้งเป็น PWA ที่หน้าหลัก
  2. ดาวน์โหลด sw.js + manifest.json
  3. วางทั้ง 2 ไฟล์ไว้โฟลเดอร์เดียวกับ HTML
  4. เปิดผ่าน local server (เช่น npx serve)

➕ เพิ่มพื้นที่ใหม่

พื้นที่ที่เพิ่มจะถูกบันทึกไว้ในเครื่องนี้ และใช้ได้ในการค้นหาครั้งต่อไป
